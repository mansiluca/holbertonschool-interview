# Insert in sorted linked list

## Description

This project contains a technical interview interview challenge involving a singly linked list in C.

The clear objective is to construct a function that inserts a number into a sorted singly linked list.

## Prototype
`listint_t *insert_node(listint_t **head, int number);`

*   `head`: A pointer to the head of the linked list.
*   `number`: The number to insert.
*   **Return:** The address of the new node, or `NULL` if it failed.

## Requirements

*   Allowed editors: `vi`, `vim`, `emacs`
*   All files will be compiled on Ubuntu 14.04 LTS using `gcc`
*   Your code should use the `Betty` style.
